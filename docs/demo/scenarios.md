# 시연 대본 (2026-11-18 확정 후보)

측정 근거: `docs/perf/demo-stability.md`. 실제 Gemini로 각 5회 대화 전체를 실행해 5회 모두 같은 화면이 나온 문장만 골랐습니다. 모든 문장은 직접 만든 가상 문장입니다.

시연 전 확인: 휴대폰 폭(375px) 브라우저, 위치 권한 "허용"(병원 목록용), Gemini 무료 한도 여유(하루 500회, 분당 15회. 대화 1번에 Gemini 2~4회).

## 1. 일반 시연 (메인) — 피부과

| 순서 | 할 일 | 화면에 나와야 하는 것 |
|---|---|---|
| 1 | 입력: **"몸에 가려운 발진이 오돌토돌 올라오고 피부에 얼룩덜룩한 반점이 생겼어요"** → 보내기 | 바로 "증상 정리 중 → 질환 분석 중" 진행 표시 |
| 2 | 추가 질문이 나오면(측정 5회에서는 나오지 않음) **"일주일 전부터 그랬고 다른 증상은 없어요"** 입력 | 결과 화면 |
| 3 | 결과 확인 | 1위 **진균 감염(피부 곰팡이) · 가능성 높음**, 이어서 약물 이상반응·수두(가능성 낮음). 권장 진료과 **피부과**. 순서 조정 안내·드문 질환 안내 없음. 퍼센트 숫자 없음 |
| 4 | 아래로 스크롤 | "주변 병원"에 피부과 병원 목록(위치 기준, 진료 중·야간·주말 표시)과 지도 |

응답 시간(측정): 결과까지 중앙값 2.3 s, 최대 2.4 s. 캡처: `docs/perf/demo-main-skin.png`

## 2. 일반 시연 (예비) — 피부과

메인 문장이 기대와 다르게 나오면 "처음부터 다시"를 누르고 이 문장으로 바꿉니다.

| 순서 | 할 일 | 화면에 나와야 하는 것 |
|---|---|---|
| 1 | 입력: **"팔꿈치와 무릎 피부에 은백색 각질이 벗겨지고 붉은 발진이 있고 손톱이 움푹 패였어요"** | 진행 표시 |
| 2 | 추가 질문이 나오면 **"몇 달 전부터 그랬고 다른 증상은 없어요"** | 결과 화면 |
| 3 | 결과 확인 | 1위 **건선 · 가능성 높음**, 여드름·진균 감염(가능성 낮음). 권장 진료과 **피부과** |

응답 시간(측정): 중앙값 2.5 s, 최대 4.7 s. 캡처: `docs/perf/demo-backup-psoriasis.png`

## 3. 위급 시연

| 순서 | 할 일 | 화면에 나와야 하는 것 |
|---|---|---|
| 1 | "처음부터 다시" → 입력: **"갑자기 가슴이 아프고 식은땀이 나요"** | 진행 표시 |
| 2 | 추가 질문이 나오면 **"방금 전부터 그래요"** | 결과 화면 |
| 3 | 결과 확인 | 맨 위에 **119 전화 버튼과 응급실 찾기(e-gen) 링크**. 1위 심근경색 · 가능성 높음. 권장 진료과 응급의학과. **주변 병원 목록은 나오지 않음**. 설명문은 119·응급실만 안내 |

응답 시간(측정): 중앙값 2.2 s, 최대 2.8 s. 캡처: `docs/perf/demo-emergency-chest.png`

## 4. 실패 시 대처

| 상황 | 화면 | 대처 |
|---|---|---|
| Gemini 일시 오류·분당 한도 초과 | "증상 분석이 잠시 어렵습니다. 잠시 후 다시 시도해 주세요." + 다시 시도 버튼 | 다시 시도 1번. 그래도 안 되면 30초 기다린 뒤 다시 시도(분당 한도는 1분 뒤 풀림). 기본 모델이 늦으면 대체 모델이 자동으로 답함 |
| 하루 한도 소진 | 같은 오류가 계속됨 | 시연 전날·당일 리허설 횟수를 줄이기. 백업으로 README 캡처를 보여 주기 |
| 1위가 다르게 나옴 | 기대와 다른 Top-3 | "처음부터 다시" → 예비 문장 |
| 위치 권한 거부 | 병원 영역에 "지도를 눌러 위치를 정해 주세요" | 지도를 눌러 위치 지정(지도가 없으면 권한 허용 후 "내 위치 다시 찾기") |
| 지도 로드 실패 | "지도를 불러오지 못했어요. 목록은 그대로 볼 수 있어요." | 목록으로 설명 |

## 5. 다시 측정하는 법
모델·프롬프트·가중치를 바꾸면 다시 측정합니다.

```bash
python infra/scripts/demo_stability.py --runs 5 --pause 20 --only fungal-2 psoriasis-3 chest --out /tmp/demo.json
```

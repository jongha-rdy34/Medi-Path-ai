# 국내에서 드문 질환의 화면 순위 가중치 (`RARE_DISEASE_WEIGHT`)

- 날짜: 2026-11-13, 모델 `dropout-2026.11.0`, 드문 질환 초안 4종(뎅기열, 말라리아, 장티푸스, E형 간염; `data/mappings/rare_in_korea.csv`)
- 방식: 화면 Top-3를 정할 때만 드문 질환의 확률에 가중치를 곱해 다시 정렬합니다. 민감 질환은 숨깁니다. 확률 원값과 권장 진료과(Top-10 확률 합)는 바뀌지 않습니다.
- 재현: `cd ml-service && python -m triage.rare_weight_eval --out ../docs/perf/rare-disease-weight.json <LLM 결과 json ...>` (API 호출 없음)
- 정답이 민감 질환인 사례는 화면에 나올 수 없어 뺐습니다(증상 2~3개 세트 317 → 289행, end-to-end 59 → 52건).

## 비교표

| 가중치 | 증상 2~3개 Top-1 / Top-3 | 드문 질환이 아닌데 드문 질환이 1위 | 정답이 드문 질환일 때 Top-3 유지 | end-to-end Top-1 / Top-3 (3.5 · 3.1 · 3.5 후보30) |
|---|---|---|---|---|
| 1.0 (조정 없음) | 0.869 / 0.972 | 3건 | 34/39 | 0.962/1.000 · 0.904/0.981 · 0.942/1.000 |
| **0.5 (추천)** | 0.862 / 0.962 | **0건** | 31/39 | 같음 |
| 0.3 | 0.851 / 0.952 | 0건 | 27/39 | 같음 |
| 0.2 | 0.844 / 0.941 | 0건 | 24/39 | 같음 |

- end-to-end 59문장에서는 어느 가중치도 결과를 바꾸지 않았습니다(드문 질환이 잘못 1위로 나온 사례가 없고, 정답이 드문 질환인 5건은 모두 Top-3 유지).
- **추천 0.5**: 드문 질환이 잘못 1위로 오르는 사례(3건)가 0.5에서 이미 0이 됩니다. 더 낮추면 이득은 없고, 실제로 드문 질환인 사례를 Top-3에서 더 많이 놓칩니다(31 → 27 → 24/39). 말라리아는 국내 접경지역에서 실제로 발생하므로 너무 낮추지 않는 편이 안전합니다.

## 예시 (화면 Top-3)

| 입력(증상 ID) | 1.0 | 0.5 | 0.3 | 0.2 |
|---|---|---|---|---|
| 미열·기침·가래 | 결핵, 폐렴, 감기 | 결핵, 폐렴, 감기 | 결핵, 폐렴, 감기 | 결핵, 폐렴, 감기 |
| 고열·기침·가래 | 폐렴, 기관지 천식, 감기 | 폐렴, 기관지 천식, 감기 | 폐렴, 기관지 천식, 감기 | 폐렴, 기관지 천식, 감기 |
| 고열·두통·전신 불쾌감 | 수두, 뎅기열, 감기 | 수두, 감기, 뎅기열 | 수두, 감기, 폐렴 | 수두, 감기, 폐렴 |
| 고열·두통·근육통 | 말라리아, 뎅기열, 감기 | 말라리아, 뎅기열, 감기 | 말라리아, 뎅기열, 감기 | 말라리아, 감기, 뎅기열 |
| 미열·두통·전신 불쾌감 | 수두, 결핵, 감기 | 수두, 결핵, 감기 | 수두, 결핵, 감기 | 수두, 결핵, 감기 |
| 미열·두통·근육통 | 말라리아, A형 간염, 수두 | A형 간염, 말라리아, 수두 | A형 간염, 말라리아, 수두 | A형 간염, 수두, 말라리아 |

- "열·두통·몸살" 계열 4가지 중 **고열·두통·근육통**은 어느 가중치에서도 말라리아가 1위입니다(모델 확률 말라리아 0.888, 다음 비희귀 질환 감기 0.011). 곱하기 방식으로는 이 차이를 뒤집지 못하며, 이때는 항목 아래의 안내("국내에서는 드문 질환입니다. 최근 해외여행이나 휴전선 인근 지역 … 방문 이력이 있다면 의료진에게 꼭 알려 주세요.")가 역할을 합니다.
- 미열·두통·근육통은 0.5부터 A형 간염이 1위로 올라옵니다.

## 화면 예시 (실제 Gemini + `dropout-2026.11.0`, 가중치 0.5, 375px)

| 입력 | 화면 Top-3 | 캡처 |
|---|---|---|
| 열이 펄펄 나고 머리가 아프고 근육이 쑤셔요 | 말라리아 89%(안내) · 뎅기열 5%(안내) · 감기 1%, 권장 진료과 내과 | `rare-disease-screen-high-fever.png` |
| 열이 조금 있고 머리가 아프고 근육이 쑤셔요 | **A형 간염 32%** · 말라리아 38%(안내) · 수두 8% | `rare-disease-screen-mild-fever.png` |

- 둘째 예시처럼 순위를 낮추면 **화면의 퍼센트가 큰 순서가 아니게** 됩니다(확률 원값을 그대로 보여 주기 때문). 안내 문구가 이유를 알려 주지만, 화면에 "국내 발생 빈도를 반영해 순서를 조정했습니다" 같은 한 줄을 더할지는 결정이 필요합니다.
- 캡처 가운데의 작은 아이콘은 개발 서버의 Vue 개발 도구 표시로, 빌드된 화면에는 없습니다.

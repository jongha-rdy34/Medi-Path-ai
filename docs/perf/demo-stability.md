# 시연 문장 안정성 측정 (2026-11-18)

- 실제 Gemini(`gemini-3.5-flash-lite`, 대체 `gemini-3.1-flash-lite`) + 분류 모델 `dropout-2026.11.0`, 로컬 스택
- 후보마다 대화 전체를 **5회** 실행(입력 문장 고정, 추가 질문에는 고정 답을 입력). 대화 사이 20초 간격, 무료 한도(15 RPM, 500 RPD) 안에서 실행. 3차례 측정에 대화 80회(Gemini 호출 약 250회: 턴마다 추출 1회 + 질문 또는 설명 1회, 대체 모델 재시도 제외)
- 재현: `python infra/scripts/demo_stability.py --runs 5 --pause 20 [--only <id> ...] --out <json>` (실행 전에 예상 호출 수를 출력)
- 결과 원본: `demo-stability.json`. 모든 문장은 직접 만든 가상 문장이며 실제 사용자 데이터는 없습니다.

## 선정 기준 (5회 모두)
1. 1위가 같은 질환이고 "가능성 높음"
2. 권장 진료과가 같고 의학적으로 타당(후보별 기대 진료과와 같음)
3. Top-3에 엉뚱한 질환이 없음(후보별 "관련 질환" 목록 밖이면 탈락)
4. 일반 시연은 위급·드문 질환 안내·순서 조정이 없음

## 해석
- **1차(증상 1~2개의 짧은 문장)**: 1위가 "보통"이거나 Top-3에 편두통·치핵처럼 엉뚱한 질환이 섞였습니다. 무릎 문장은 1위 자체가 바뀌었고(골관절염 1회 → 관절염 4회), 목 문장은 추가 질문만 반복하다 결과가 나오지 않았습니다(증상이 충분히 모이지 않음).
- **2·3차(전형 증상 3~4개)**: 1위는 매번 같고 "가능성 높음"이 되었습니다. 그러나 1위 확률이 0.95 이상이면 2·3위는 0에 가까운 값이어서 모델이 거의 아무 질환(편두통, 치핵, 갑상선기능항진증)으로 채웁니다. 여드름·무릎/고관절·요로감염·농가진이 이 이유로만 탈락했습니다.
- 2·3위까지 관련 질환이 나온 것은 피부 질환 문장(진균 감염, 건선)뿐이라 일반 시연 2개가 모두 피부과입니다. 진료과를 다양하게 보이려면 "가능성 낮음이면서 확률이 아주 작은 항목은 화면에서 빼기" 같은 표시 규칙이 필요합니다(제품 결정 사항, 이번에는 바꾸지 않음).
- 무좀 문장의 3위 "수두"는 처음 기준표에 없었지만 가려운 발진이라는 공통점이 있어 관련 질환으로 인정했습니다(`demo_stability.py`에 근거 주석).

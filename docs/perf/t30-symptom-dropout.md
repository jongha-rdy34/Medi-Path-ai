# T30 후속 C-2: 증상 일부를 빼고 학습(symptom dropout) 비교

- 날짜: 2026-11-13, 시드 42, 같은 그룹 분할(학습 222 + 검증 41, 테스트 41 조합, 겹침 0)
- 재현: `cd ml-service && python -m triage.compare --out ../docs/perf/t30-symptom-dropout.json <LLM 결과 json ...>`
  (모델 파일 `models/dropout-2026.11.0.joblib`도 저장. 모델 파일은 gitignore 대상)
- 원인: Kaggle 조합은 증상이 평균 7.65개(최소 3개)인데, 실제 사용자는 2~3개를 말합니다.
- 보강: 학습·검증 조합마다 원본 + 증상을 50% 확률로 뺀 사본 10개(최소 2개 남김) + 증상 2개·3개 무작위 사본 1개씩. 증상은 빼기만 하고 더하지 않으며, 위험 요인은 넣지 않습니다. 학습 행 263 → 3,371
- 새 평가 세트 `short_test`: 테스트 조합(학습에 없는 41개)에서 증상 2개·3개를 무작위로 골라 만든 317행

| 노이즈 테스트 (205) | Top-1 / Top-3 | 0.946 / 0.995 | 0.961 / 0.995 |

| end-to-end 3.5-flash-lite 후보 30개(T30) (59) | Top-1 / Top-3 / 진료과 | 0.814 / 0.932 / 0.949 | 0.915 / 0.983 / 0.949 |

end-to-end는 저장된 LLM 추출 결과를 다시 쓰므로 API를 부르지 않습니다.

| 입력(증상 ID) | 베이스라인 | 보강 |
|---|---|---|

| 고열·두통·근육통 | 말라리아, AIDS, 뇌출혈 마비 | 말라리아, 뎅기열, 감기 |

- "열·기침·누런 가래 → 폐렴 Top-3": 베이스라인 0/2 → 보강 2/2

- 표는 모델 출력 그대로입니다. AIDS 같은 민감 질환은 서비스 화면에서 숨깁니다(SPEC 6절).

## 해석과 남은 점
- 짧은 입력과 end-to-end Top-1·Top-3가 크게 오르고, 기존 그룹·노이즈 지표는 떨어지지 않았습니다.
- end-to-end **1순위 질환의 진료과 일치율**은 3.5 전체 사전에서 0.983 → 0.966, 3.1에서 0.983 → 0.949로 조금 내렸습니다(59건 중 1~2건). 아래 "진료과가 어긋난 사례" 참고.
- `short_test`의 증상 2~3개 부분집합은 다른 학습 조합의 부분집합과 같을 수 있습니다(같은 질환은 증상을 공유). 조합 단위 누설은 없지만 완전히 새로운 입력은 아닙니다.
- 말라리아·뎅기열처럼 국내에서 드문 질환이 짧은 발열 입력에서 여전히 상위에 나옵니다. 질환별 유병률을 반영하지 않는 데이터셋의 한계이며, 보정은 이번 범위 밖입니다.
- **결정(2026-11-13, 사용자 승인)**: 기본값을 `MODEL_VERSION=dropout-2026.11.0`으로 교체. 이 결과는 T50(BERT)의 새 비교 기준입니다.

## 진료과가 어긋난 사례 (교체 전 확인, 2026-11-13)

end-to-end 지표의 "진료과"는 **1순위 질환의 주 진료과**입니다. 서비스는 다르게 계산합니다: 모델 Top-10 확률을 주 진료과별로 더해 가장 큰 진료과(민감 질환 포함, `backend/triage/service.py`의 `department_scores`).

| 결과 파일 | 사례 | 문장(평가셋, 합성) | 정답 질환(진료과) | 보강 모델 Top-3 (확률, 진료과) | 서비스 진료과 합(보강) | 서비스 진료과 합(베이스라인) |
|---|---|---|---|---|---|---|
| 3.5 전체·3.1·3.5 k30 | c048 | 콧물이랑 재채기가 계속 나고 눈이 빨개졌어요 | 알레르기(13) | 감기 0.747(01), 알레르기 0.066(13), 치핵 0.007(04) | **01** = 0.768, 13 = 0.066 | **01** = 0.163, 13 = 0.111 |
| 3.1·3.5 k30 | c047 | 화장실을 자주 가는데 소변볼 때 너무 따가워요 | 요로감염(15) | 약물 이상반응 0.239(14), 요로감염 0.208(15), 당뇨병 0.145(01) | **14** = 0.239, 15 = 0.208, 01 = 0.173 | **01** = 0.120, 14 = 0.116, 15 = 0.107 |
| 3.5 k30 (반대로 좋아짐) | c009 | 몸 여기저기에 붉은 반점이 … 몸살 기운이 있어요 | 수두(14) | 수두 0.608(14), 뎅기열 0.267, 말라리아 0.037 | **14** = 0.616 | 01 = 0.327 |
| 3.5 k30 (반대로 좋아짐) | c046 | 한쪽 머리가 욱신거리고 속이 쓰리고 체한 것 같아요 | 편두통(02) | 편두통 0.528(02), 고혈압 0.055, 뇌출혈 마비 0.051 | **02** = 0.528 | 01 = 0.158 |

- **원인(한 줄)**: Kaggle 데이터의 증상 겹침입니다. 감기 조합에는 콧물·재채기·눈 충혈이 다 들어 있고 알레르기 조합에는 콧물·눈 충혈이 없으며(c048), 약물 이상반응 조합에 `burning_micturition`이 들어 있습니다(c047). 보강으로 증상 2~3개짜리 부분집합을 배우면서 이 겹침이 그대로 드러났습니다. 매핑(`disease_department.csv`) 오류나 합산 방식의 문제는 아닙니다.
- c048은 서비스 진료과가 두 모델 모두 내과(01)라 화면 결과는 같습니다. c047은 서비스 진료과가 베이스라인 내과(01) → 보강 피부과(14)로 바뀌었고, 둘 다 정답(비뇨의학과 15)이 아닙니다.
- **서비스 방식 진료과 일치율**(59건): 3.5 전체 0.949 → 0.966, 3.1 0.932 → 0.949, 3.5 k30 0.898 → 0.949. 보강 모델이 더 좋습니다.
- **위급 질환 퇴행 없음**: 정답이 응급의학과(24)인 4건(심근경색 2, 뇌출혈 마비 2)은 두 모델 모두 서비스 진료과 24입니다.

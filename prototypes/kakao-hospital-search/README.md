# kakao-hospital-search (팀원 프로토타입 자리)

- [ ] Kakao 키(JavaScript 키, REST API 키)가 코드에 들어 있지 않은지. 필요하면 `.env` 이름만 적기
- [ ] 실행 방법(필요한 키 이름, 실행 명령)을 이 README에 적기
- [ ] 쓰는 Kakao API(지도 SDK, 로컬 키워드·카테고리 검색)와 응답 필드를 적기. T21에서 `contracts/openapi.yaml`의 `Hospital` 스키마를 맞출 때 씁니다

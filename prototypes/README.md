# prototypes/

팀원이 따로 만든 프로토타입을 **본 코드(`backend/`, `frontend/`)와 섞지 않고** 먼저 올려 두는 곳입니다.
본 코드로 옮길 때는 해당 태스크(예: T21)의 PR에서 옮기고, 옮긴 뒤 이 폴더의 사본은 지웁니다.

| 폴더 | 내용 | 담당 | 본 코드로 옮길 태스크 |
|---|---|---|---|
| `kakao-hospital-search/` | 카카오맵에서 현재 위치 기준 진료과(예: "내과")로 근처 병원 검색 | 팀원 | T21 (`backend/` 병원 검색 앱 + `frontend/` 지도) |

## 규칙
- API 키는 넣지 않습니다. 키가 필요한 값은 `.env` 또는 코드 밖 설정으로 빼고, 이름만 README에 적습니다(저장소가 public입니다).
- 각 프로토타입 폴더에 실행 방법을 담은 `README.md`를 둡니다.
- 프로토타입은 CI 대상이 아닙니다.
